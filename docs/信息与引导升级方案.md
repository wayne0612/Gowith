# Gowith 信息与引导升级方案

- 版本：1.0
- 日期：2026-09-25
- 前置：用户方向定调——按商业软件标准打磨信息与细节；核心出发点「用户爽」
- 关联：`docs/爽感打磨方案.md`（动效与峰值时刻）、价值体系讨论（价格/天数/双口径均价）

## 0. 出发点：三条信息排座次的原则

用户原话：「有很多地方是用户平时不那么在意，但又必须知道信息在哪里的。」拆成三条铁律：

1. **高频上浮**：与当前任务直接相关的数据（本次带几件、带多少钱、带回没有），必须出现在视线第一落点（资产卡），不需要点任何东西。
2. **低频收纳，位置固定**：不天天看、但需要时必须找得到的数据（单件的持有天数、携带次数、单次成本、编辑分类），收进固定容器（物品编辑器顶部 / 长按菜单），位置一旦定下永不挪窝——"必须知道信息在哪里"的答案是**位置可预期**，不是全部摆出来。
3. **一页一主任务**：每个页面用一句话定义身份，页面上一切与主任务无关的常驻内容，在用户熟练后自动退场。

**五个页面的身份定义**（一切增删改查以此为准绳）：

| 页面 | 身份一句话 | 主任务 |
|---|---|---|
| 物品库 | 货架 + 数据台 | 添加物品、看清家底 |
| 拿东西 | 出发的操作台 | 核对清单、带价值出门 |
| 检查 | 清点的对账台 | 逐项确认、损失可见 |
| 地图（进阶） | 空间的总览台 | 地点、围栏、分布 |
| 我的 | 资产与偏好的沉淀地 | 统计、待确认、设置 |

## 1. 全页面信息审计（增 / 删 / 改 / 查）

### 1.1 物品库（本轮改造重心）

| 操作 | 内容 | 理由 |
|---|---|---|
| **增** | 资产卡 badge：「全部 X 类」→「**总价值 ¥X**」（有任何价格录入时显示） | 类目数量是弱信息；总价值是用户口中的"真正关心的数据" |
| **增** | 资产卡底部细行：**随身 ¥a · 在家 ¥b · 在外 ¥c**（按地点分布的价值速览） | 地点×价值交叉是 Gowith 独有维度；一行解决"东西都值多少钱、都在哪" |
| **增** | 货架行副标题：价格已录的物品显示「¥299 · 在「玉林的家」」 | 单件价值属于高频上浮 |
| **查** | 单件统计（持有天数 / 携带次数 / 日均 / 单次成本）→ 收纳进**编辑器顶部统计条**，位置固定 | 低频但必须可查；不放货架，避免行过载 |
| **改** | 资产卡右指标保持状态化：会话中「携带中 N 件」/ 平时「已装入背包 M 件」 | 已实现，保持 |
| **删** | 无整块删除；分类 chips 保留（分类是组织货架的骨架） | — |

**改造后的物品库资产卡**：
```
┌──────────────────────────────────┐
│ 物品库 · INVENTORY      总价值 ¥8,420 │
│   2 件        │   1 件(橙)   │
│ 物品库总数     │   携带中      │
│  随身 ¥1,180 · 在家 ¥7,240 · 在外 ¥0  │
│        点 + 添加物品 · 装包          │
└──────────────────────────────────┘
```

### 1.2 拿东西

| 操作 | 内容 | 理由 |
|---|---|---|
| **增** | 清单卡标题：「通勤包清单 · 2 件 · **约 ¥1,180**」 | "我要带着多少钱出门"是出发前最后一眼的安全感数据 |
| **增** | 「上次出门」一键复装卡（物品齐全时显示，装包后消失） | 最高频的真实动作是"和上次一样"；逐个触发飞球形成连击爽感 |
| **删** | 「出行后」说明卡在**完成首次出行后自动退场**（新手期专属） | 熟练后即噪音；一页一主任务 |
| **改** | 资产卡 badge 保留背包名（它是切换背包的入口） | — |

### 1.3 检查

| 操作 | 内容 | 理由 |
|---|---|---|
| **增** | 资产卡「待确认」下方或 tips 卡首行：**「待确认价值 ¥X」** | 损失厌恶是清点认真度的放大器；金额让"待确认"有分量 |
| **增** | 峰值时刻联动：全部带回时仪式画面显示「带回 ¥X 的家当」 | 承接爽感方案 2.1 |
| **改** | 无 | 现有结构已符合对账台身份 |

### 1.4 地图（进阶）

- **增**：地点卡数据行「物品 2 · 背包 1」→「物品 2 · 背包 1 · 在此 ¥X」。
- 其余不动（低频总览台，保持轻）。

### 1.5 我的

- **增**：头部卡片升级为**随身资产总卡**：总价值 / 件数 / 完成清点次数 / 连续零遗失天数（四格或两行）。
- 保持：待确认入口卡、各设置组、v1.1 版本号。
- 查：全部历史统计仍收在历史页，不上浮。

### 1.6 数据层与录入（价值体系落地，承接上轮讨论）

- `GowithItem` / `GowithBackpack` 增加可选字段 `purchasePrice: Double?`、`purchaseDate: Date?`（默认建档日）；Codable 兼容旧数据。
- 编辑器：名称卡下方或同卡内追加「价格」字段（数字键盘、可留空、可清空）；**不填价格的用户永远看不到任何金额 UI**。
- 计算口径（实时算，不落盘）：
  - 持有天数 = 今天 − purchaseDate
  - 日均持有 = price ÷ max(1, 持有天数)
  - **携带次数 = 历史会话（含进行中）中该物品出现的次数**（Gowith 独有）
  - **单次使用成本 = price ÷ max(1, 携带次数)**（核心飞轮：每出行一次掉一格）
- 编辑器顶部统计条（收纳位的"查"）：`持有 365 天 · 携带 42 次 · 日均 ¥8.2 · 单次 ¥71`（无价格则只显示持有天数与携带次数）。

## 2. 实操引导系统（CoachMark 引擎）

### 2.1 设计原则

1. **在动作现场教，不在课堂教**：教学动画只讲三步心智模型；真正的操作逻辑靠"走到哪、第一次用到哪，就弹一次"的现场引导。
2. **弹窗 + 箭头**：气泡（标题 + 一句话 + 「知道了」）+ 指向目标的箭头/高亮，一次只出现一个。
3. **完成即毕业**：用户完成对应动作，引导永久消失（写 UserDefaults）；点「知道了」也消失但动作未完成则下次进入同页再示一次（最多 3 次）。
4. **全局可重置**：「重新观看引导动画」同时重置全部 coach 标记。
5. **不打架**：不与确认弹窗/sheet/权限弹窗同时出现；会话关键时刻（确认出发、清点中）不弹。
6. **可达性**：VoiceOver 可聚焦朗读；Reduce Motion 用淡入淡出。

### 2.2 触点清单（首批 5 个）

| # | 触发时机 | 指向 | 文案（气泡） |
|---|---|---|---|
| C1 | 货架首次有物品、尚未装入任何背包 | 某行的 + 按钮 | 「点 + 把物品装进背包」 |
| C2 | 首次有物品装入成功 | 「拿东西」Tab 角标 | 「装入的物品都会出现在这里，随时可以出发」 |
| C3 | 首次进入拿东西页且清单非空 | 悬浮主按钮 | 「核对完成，点这里开始出行」 |
| C4 | 首次进入出行中（away） | 锁定说明卡 | 「清单已自动锁定；到家或到达地点会自动提醒你清点」 |
| C5 | 首次进入回家清点 | 第一条清点行 | 「点整行打勾，核对每件东西是否带回」 |

### 2.3 技术实现要点

- `enum CoachKey: String` + `@AppStorage("coach.<key>")`；视图修饰器 `.coachMark(key, arrow:.up/.down, title:, message:)`。
- 第一版用**固定锚点**（Tab 栏上方 / 主按钮上方 / 首卡下方），不做通用挖洞 spotlight——骨架固定（头部/主按钮/Tab 栏），固定锚点已覆盖 5 个触点，复杂度减半。
- 单一全局队列：`shownCoachKey: CoachKey?` 状态在 RootView，逐个消化。

## 3. 开屏 Hero 与教学动画升级

### 3.1 冷启动品牌帧（Hero）

- iOS LaunchScreen 必须静态，所以品牌帧放在**启动后**：黑底（或当前模式底色）上「Gowith」字标 + 橙色句点落下弹跳（spring，0.45s）→ 整体 0.8s 内交叉淡出进入当前页。
- 规则：仅冷启动显示；总时长 ≤0.9s；点击任意处立即跳过；热启动（从后台回来）不显示；不给启动增加可感知延迟（动画与数据加载并行）。
- 句点落定的位置即品牌记忆点（Gowith**.**）。

### 3.2 教学三帧重做（从"看图"到"看戏"）

- **用真实组件的微缩动画替换静态 emoji**：
  - 帧 1「放上货架」：一行货架 + 号被点按 → 行转黑显示"已装入"（循环 2s）
  - 帧 2「装进背包」：飞球从 + 飞向角标、角标弹跳（复用真实飞球动效，循环 2s）
  - 帧 3「回家打勾」：清点行圆圈描边生长为 ✓（循环 2s）
- **步骤易记**：三帧标题动词化——放上货架 / 装进背包 / 回家打勾（放→装→勾，三个字就能复述）；序号 01/02/03 保留。
- 文案每帧 ≤2 行；帧间 spring 滑动；页点升级为细进度条；末帧「开始体验 →」不变。
- 全部动效尊重 Reduce Motion（循环动画降为静态帧）。

### 3.3 引导设置页微调

- 位置卡成功态已有橙圈 + 「位置已准备好」；补充保存成功 → 主界面的 reveal 转场（内容淡入 + 资产卡从下方 12pt 浮起）。
- 其余不动（信息简单、操作简单已达标）。

## 5. 验收

1. 信息层：以「出差党一日」剧本走查，每个页面回答三个问题——这页是干什么的？我最关心的数字在哪？我要找的低频信息在哪（且位置可预期）？
2. 价值层：不录价格 → 全 App 无任何金额 UI；录入后 → 五页联动正确、单次成本随清点下降。
3. 引导层：全新安装走完五触点各一次；重置后可复现；与权限弹窗/确认框不冲突。
4. 开屏层：冷启动 ≤0.9s 品牌帧；教学三帧循环动画流畅；Reduce Motion 全降级。
5. 全部动效与引导均通过 VoiceOver 朗读检查。
