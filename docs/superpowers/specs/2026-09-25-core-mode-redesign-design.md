# Gowith 核心模式重构设计规格书

- 日期：2026-09-25
- 状态：已确认（经可视化迭代 v1→v7 定稿）
- 范围：基础/进阶双模式、4 Tab 核心闭环、黑白视觉体系、首启教学动画

---

## 1. 背景与目标

现有 Gowith 为 4 Tab 结构（背包/物品库/地图/我的），彩色场景色体系。本次重构：

1. **运行时双模式**：顶部胶囊开关切换「基础 / 进阶」，无需重新构建。
2. **基础模式聚焦核心闭环**：添加物品 → 装包出行 → 回家清点，App 主动引导而非让用户自己思考。
3. **进阶模式解锁全部能力**：地图/地点、历史统计等，整体转深色。
4. **视觉体系更换为黑白极简**（参考黑白色系 App）：黑 #111、白、灰阶，唯一强调色橙 #FF5A26。
5. **引导信息从常驻卡片改为首启教学动画**，熟练用户不受干扰。

| `surface` | rgba(255,255,255,0.94) | rgba(255,255,255,0.05) | 卡片 |
| `surfaceBorder` | #ECECF0 | #26262B | 卡片描边 |
| `ink` | #111111 | #F4F4F5 | 主文字/主按钮底 |
| `inkSecondary` | #71717A | #8B8B93 | 次文字 |
| `inkTertiary` | #A1A1AA | #A1A1AA | 弱文字 |
| `hairline` | #F0F0F2 | rgba(255,255,255,0.07) | 行分隔线 |
| `accent` | #FF5A26 | #FF5A26 | **全局唯一强调色** |
| `accentSoft` | #FF8C5A | #FF8C5A | 黑卡上的强调文字 |

### 2.3 形状与间距

- 圆角：手机卡 20 / 内容卡 18 / 行图标 12 / 按钮·胶囊·Tab 全圆角（capsule）
- 页面横向 padding 14；模块间距 10；行高 56（图标 38 + 间距）
- 资产卡纹理：白色低透明（opacity 0.14）SVG 曲线/圆环，每页不同（物品库=流线、拿东西=双圆环、检查=✕+圆、历史=无纹理深色卡）

### 2.4 动效

| 场景 | 参数 |
|---|---|
| 胶囊滑块 | 0.38s cubic-bezier(0.34,1.4,0.44,1) 弹性平移，文字颜色 0.3s 过渡，light impact 触感 |
| 装包（点 +） | ① + 旋转 45° 变 ✕ 且转橙色 0.3s；② 橙色小球（14pt）从按钮飞入「拿东西」Tab 0.55s cubic-bezier(0.3,0.7,0.4,1)，终点 scale 0.4 + 淡出；③ 角标弹跳 scale 1→1.45→1（0.3s）；④ 图标转黑底、状态字变橙 |
| Tab 切换 | 选中胶囊 0.25s ease |
| 页面内容 | 尊重 Reduce Motion，开启时全部降为透明度渐变 |

## 3. 全局结构规则

每个页面手机框内严格四层：

```
┌─────────────────────────┐
│ Gowith.      [基础|进阶] │ ← 固定头部，毛玻璃 backdrop blur，z 轴最高
├─────────────────────────┤
│  资产卡片 / 内容卡 × N    │ ← 唯一可滑动区（ScrollView）
│  …                       │
├─────────────────────────┤
│  [ 黑色主按钮 ]           │ ← 悬浮钉底（仅拿东西/检查页有），渐隐托底
│  ▤物品库 ◍拿东西 ◎检查 ☺ │ ← 固定 Tab 栏
└─────────────────────────┘
```

- **头部固定**：`safeAreaInset(edge:.top)`，背景 `bg` 86% 透明度 + blur(10)。
- **主按钮悬浮**：`safeAreaInset(edge:.bottom)` 置于 Tab 栏之上，下方垫 `LinearGradient(bg → 透明)` 高 26pt 的渐隐托底，避免内容从按钮下露出。
- **Tab 栏固定**：4 格（基础）或按需扩展（进阶）。选中项黑底白字胶囊（深色模式反转）。

## 4. 核心组件规格

### 4.1 胶囊模式开关 `ModeCapsule`

- 尺寸：96×30；轨道浅灰 rgba(255,255,255,0.85) + 1px #E4E4E7 描边；深色模式轨道 rgba(255,255,255,0.08)。
- 滑块：药丸形（stadium），44×24，**恰好包裹「基础」/「进阶」文字且文字始终位于滑块几何中心**。黑色微渐变（#2A2A2E→#000）。
- 状态：基础=滑块在左，选中文字白色 Bold；未选中灰色 #A1A1AA。进阶=滑块在右，且**进阶模式下整体页面转深色**。
- 点击任意一侧或滑块本身均可切换；切换触发 light impact haptic。
- 持久化：`@AppStorage("gowith.appMode")`，枚举 `AppMode { basic, advanced }`。

### 4.2 资产卡片 `AssetCard`

黑色大卡（渐变 #26262B→#000 72%），圆角 20，内边距 14/18/13。四层结构：

1. **天头（左右）**：左「页面名 · 英文大写」（9.5pt Bold tracking 2，白 50%）；右 橙色小标签（#FF8C5A）。
2. **中腰（左 ┆虚线┆ 右）**：左右两个数据半区居中，中间 1.5px 垂直虚线（白 28%）。
   - 主数字 50pt ExtraBold + 单位 13pt 弱化；
   - 左=主数据（白色），右=副数据（**橙色 #FF5A26**）；
   - 数字下各一行 10pt 标签。
3. **slogan（居中）**：tracking 5，句读点橙色，上接 1px 白 12% 分隔线。
4. **地脚 CTA（居中）**：10.5pt，关键词橙色加粗。

各页数据映射：

| 页面 | 左 | 右 | 右上标签 | slogan | CTA |
|---|---|---|---|---|---|
| 物品库 | 物品库总数 N 件 | 已装入背包 M 件（橙） | 全部 X 类 | 一件不落 · 安心出门 | 点 + 把货架物品装入背包 |
| 拿东西 | 已装入 M 件 | 货架剩余 K 件（橙） | 当前背包名 | 装齐了吗 · 出门再查 | 齐了？点底部 开始出行 |
| 检查 | 已带回 A 件 | 待确认 B 件（橙） | 回家清点 | 逐项打勾 · 一件不落 | 全部勾完即可 完成清点 |
| 历史（进阶） | 完成清点 N 次 | 遗失物品 L 件（橙） | 本月 | 次次安心 · 件件有着落 | 保持住 零遗失 记录 |

### 4.3 货架行 `ShelfRow`（物品库/拿东西）

图标 38 圆角 12（灰底 #F0F0F2，已装入转黑底白字）→ 名称 13 Bold + 状态 10pt → 右侧 + 按钮（29 黑圆）。
已装入状态：图标黑底、状态字橙色「已装入背包」、+ 旋转 45° 变 ✕ 橙底（再点=移除）。

### 4.4 清点行 `CheckRow`（检查页）

整行可点。已带回：图标黑底 + 实心黑 ✓ 圆；待确认：灰底图标 + 灰描边空心圆。点击即切换，附 selection haptic。

### 4.5 Tab 角标 `TabBadge`

橙色胶囊数字，位于「拿东西」Tab 右上（top 1 / right 8），新增时弹跳动画；「检查」有待确认物品时同样显示。

### 4.6 分类胶囊条 `CategoryChips`

横滑胶囊条：全部/随身/数码/出行/洗护，选中黑底白字。

## 5. 页面规格（7 屏）

### 5.1 物品库（基础 Tab 1）

- 资产卡片（数据见 4.2）。
- 分类胶囊条。
- 货架按分类分组为多个内容卡（随身/数码/出行…），每卡分节标题 + 行列表。
- 底部内嵌虚线「添加新物品到货架…」入口。
- 点 + 触发装包动画全套（4.2 动效表）。

### 5.2 拿东西（基础 Tab 2）

- 资产卡片 + 分类胶囊条（已装入 N）。
- 「通勤包清单」卡：已装物品行（实心 ✓，整行可点取消）。
- 「可能还想带」卡：建议项（如雨伞附「今天有雨 · 建议带上」）。
- 悬浮主按钮「开始出行（N 件）」。
- 「出行后」说明卡：离开围栏自动记录、到达触发清点。

### 5.3 检查东西（基础 Tab 3）

- 资产卡片（已带回/待确认）。
- 清点列表卡（整行点按切换），底部内嵌「找不到可标待确认，3 天内补登」说明。
- 「清点小贴士」卡（如"耳机最后在公司出现过"——数据来源：物品最后 location snapshot）。
- 悬浮主按钮「完成清点（A/N）」；有待确认项时弹确认 alert（沿用现有逻辑）。

### 5.4 我的（基础 Tab 4）

- 头像 + 统计行（N 件物品 · 完成 M 次清点）。
- 分组列表：偏好（外观/提醒/触感）、功能（重看引导动画/历史记录/定位与围栏）、支持（反馈/关于）、账号（iCloud 同步占位/清空数据）。
- 「重新观看引导动画」重置 `@AppStorage("gowith.hasSeenTutorial")`。

### 5.5 进阶 · 地图与地点（深色）

- 头部胶囊滑块翻转为白底黑字。
- 深色地图卡（MapKit 真实地图，深色样式）+ 当前位置橙点 + 地点大头针。
- 已保存地点列表卡 + 添加地点入口。
- 围栏提醒开关组。

### 5.6 进阶 · 历史与统计（深色）

- 资产卡片（深色变体：#2E2E33→#101012 + 描边）。
- 最近清点列表（状态圆点：绿=完成，橙=待确认）。
- 统计卡：清点完成率、连续零遗失天数。

### 5.7 首启教学动画

- 触发：首次启动（`hasSeenTutorial == false`）；「我的」中可重看。
- 三帧全屏横滑卡片：01 添加（📦）/ 02 装包（🎒）/ 03 清点（✅），页码指示器（选中为长条黑），底部「跳过 ›」，末帧「开始体验 →」。
- 每帧大 emoji/插画位 + 15pt Bold 标题 + 11pt 两行说明。
- 3 秒内可看完；支持 Reduce Motion 降级为淡入。

## 6. 技术架构

### 6.1 模式状态

```swift
enum AppMode: String { case basic, advanced }
// RootView: @AppStorage("gowith.appMode") private var appMode: AppMode = .basic
```

- `RootView` 重构：**基础模式固定 4 Tab**：物品库 / 拿东西 / 检查 / 我的；**进阶模式 5 Tab**：物品库 / 拿东西 / 检查 / 地图 / 我的，且全局注入深色配色。
- 历史页在进阶模式下作为独立页面，从「我的 → 功能 → 历史记录」进入（不占 Tab 位）。
- 模式切换不销毁数据，仅切换视图与主题。

### 6.2 现有代码映射

| 现有 | 去向 |
|---|---|
| `ItemLibraryView` | 重写为物品库货架页（保留 toggleItem 逻辑） |
| `BackpackView` 装包部分 | 并入拿东西页 |
| `GoView` | 拆入拿东西（出行前）与检查（arrived/checking）页 |
| `PlacesMapView` | 移入进阶模式地图页 |
| `ProfileView`/`HistoryView` | 我的面板（基础）+ 历史页（进阶） |
| `GowithHeroView` | 替换为首启教学动画（三帧） |
| `GowithSetupView` | 保留（教学动画播完后进入，仍负责首个地点/背包/物品创建） |
| DesignSystem 彩色令牌 | 新增黑白令牌组，旧场景色仅保留在进阶深色页之外不做使用 |

### 6.3 数据模型

无破坏性变更。沿用 `GowithStore` JSON 持久化、地理围栏（50m、`kCLLocationAccuracyBest` 十米级 + distanceFilter 10）、pending 3 天转 lost 规则。新增仅两个 `@AppStorage`：`gowith.appMode`、`gowith.hasSeenTutorial`。

### 6.4 约束保留（项目硬性规则）

- 50m 围栏内才能取放物品；至少保留一个地点；进行中会话的背包不可删；pending 超 3 天自动转 lost 且孤儿物品归位出发地。

## 7. 验收标准

1. 胶囊开关在所有页面固定右上、可切换、文字居中于滑块内，切换伴随弹性动画 + haptic。
2. 基础模式 4 Tab；进阶模式深色 + 地图/历史可用。
3. 物品库资产卡片双数字（左总数/右已装橙色），点 + 有完整飞球+角标弹跳动画。
4. 拿东西/检查主按钮悬浮钉底不随滚动移动。
5. 首启教学动画仅首次出现，「我的」可重看。
6. iPhone 模拟器编译通过，深浅色外观正确。
7. 提交信息遵循 Conventional Commits。

## 8. 任务拆分（实现顺序）

1. **T1 设计令牌 + AppMode**：黑白令牌、深色变体、`ModeCapsule` 组件、RootView 模式注入。
2. **T2 全局骨架**：固定头部、悬浮主按钮容器、4 Tab 栏（含角标）。
3. **T3 物品库页**：资产卡片 + 分组货架 + 装包飞球动画。
4. **T4 拿东西页**：清单 + 建议 + 开始出行。
5. **T5 检查页**：清点列表 + 小贴士 + 完成清点（沿用会话结算逻辑）。
6. **T6 我的面板**：分组设置 + 教学动画重看。
7. **T7 进阶模式**：深色主题 + 地图页 + 历史页。
8. **T8 首启教学动画**：三帧横滑 + 跳过 + 重看入口。
9. **T9 联调验收**：模拟器全模式走查、动效/haptic、编译与提交。
