# 真机回归清单（地理围栏核心闭环）

> 模拟器的区域监测事件（`didExitRegion` / `didEnterRegion`）不可靠，**本清单必须在真机上执行**。
> 这是 Gowith 整个产品闭环（出门 → 到达 → 清点）的核心路径，每次发版前建议完整走一遍。

## 前置准备

1. 用免费 Apple ID 经 Sideloadly / AltStore 签名安装 `dist/Gowith-1.0.1-unsigned.ipa`（教程见 [iPhone安装教程.md](iPhone安装教程.md)，7 天有效）。
2. **设置 → 隐私与安全性 → 定位服务 → Gowith → 始终**（后台围栏监测的前提；App 内首次发起出行时也会弹）。
3. 允许 Gowith 发送通知。
4. 准备两个地点：**家**（用「使用当前位置」在家里设置，保证围栏 50 米准确）+ **一个常去的地点**（如公司/健身房，最好到场后用当前位置设置）。

## 场景 1：发起出行（围栏内校验）

| 步骤 | 预期 |
| --- | --- |
| 在家 50 米内，「拿东西」页装入 ≥1 件物品 | 角标计数 + 飞球动画正常 |
| 点「开始出行（N 件）」→ 确认 | 进入「出行中 · 清单已锁定」只读态，主按钮变为「到达后自动提醒清点」（禁用） |
| 切到「物品库」页 | 顶部出现「出行进行中 · 清单已锁定」说明卡，行内 + 按钮置灰、编辑入口禁用（**v1.0.1 新增的锁定行为**） |
| 系统弹「允许"Gowith"始终使用定位？」 | 选「允许」 |

## 场景 2：离开出发地

| 步骤 | 预期 |
| --- | --- |
| 携机走出家约 50 米外（建议实际走一段） | 无打断；拿东西页保持出行中，已出门时长在增长 |

## 场景 3：到达其他地点（核心）

| 步骤 | 预期 |
| --- | --- |
| 走进公司/健身房 50 米内 | 收到本地通知「可能已经到达「xx」」 |
| 打开 App | 自动切到「检查」页的「已到达」态 |
| 点「开始检阅」→ 选择放入的物品 → 「完成放入目的地」 | 选中的物品与背包归属切换到该地点；未选中的继续携带 |

## 场景 4：回家清点（核心）

| 步骤 | 预期 |
| --- | --- |
| 走回家 50 米内 | 收到到达通知；检查页进入「回家清点」 |
| 逐项打勾 / 留一件不打勾 | 状态实时切换；完成时弹「还有物品待确认」 |
| 「继续完成」 | 会话完成；已带回/待确认物品归位到出发地；检查 Tab 角标显示待确认数 |

## 场景 5：手动兜底

| 步骤 | 预期 |
| --- | --- |
| 出行中点「手动确认到家或地点…」→ 选一个地点 | 与自动到达同等效果（围栏不触发时的兜底路径） |
| 出行中直接杀掉 App 再打开 | 会话仍在，页面恢复出行中状态 |

## 场景 6：待确认 3 天过期（可用历史数据验证）

| 步骤 | 预期 |
| --- | --- |
| 历史记录 → 打开有待确认物品的会话 → 详情页补登为「已带回」或「遗失」 | 状态可改，物品地点随之归位 |
| 待确认超过 3 天（可临时改设备日期验证） | 自动转「遗失」；物品库物品 lostCount +1，孤儿物品归位出发地 |

## 常见问题排查

- **通知没收到**：确认定位是「始终」而非「仅使用期间」；确认通知权限开启；重启手机后需打开一次 App 让系统重新注册区域。
- **围栏一直不触发**：走到地点中心附近重新保存一次位置（GPS 漂移可能导致围栏中心偏移）；单个 App 最多同时监听 20 个区域。
- **7 天后 App 打不开**：免费签名过期，用 Sideloadly 重签即可（数据不丢失）。
