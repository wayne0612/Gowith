# Gowith 使用手册

> **Gowith = Go + with，带着走。**
> 它管住「家 → 背包 → 出行 → 清点」整条链路：家里有什么、包里装了什么、出门带没带、回家丢了没——一件都看得见。
> 口号：**出门带的，一件不少。**

- 适用版本：v1.1.1 及以上
- 全部数据只存在你的手机本地，不需要注册账号

---

## 1. 先弄懂五个词

| 词 | 是什么 | 好比 |
|---|---|---|
| **家** | 你保存的地点（家、公司、学校…），物品和背包都放在某个家里 | 房子 |
| **货架** | 一个家里登记的全部物品 | 房间里的架子 |
| **背包** | 装物品出门的容器，放在某个家里 | 书包 |
| **出行** | 从「当前所在的家」带着背包出门的一段行程 | 出门 |
| **清点** | 到家后逐件确认带出的东西有没有带回来 | 对账 |

一句话串起来：**物品放在家的货架上 → 装进背包 → 出行 → 回家清点 → 没带回来的进入「待确认」。**

## 2. 三步上手

1. **建家**：首次打开按引导输入家的名字（如「广西玉林」），用地图选好位置。这个位置用来判断你是否「到家」。
2. **建背包、上货架**：引导里顺手建第一个背包和第一件物品。之后点右下角橙色 **＋** 可随时添加物品 / 背包 / 地点。
3. **装包出发**：在物品页点物品行的 **＋** 把它装进背包 → 切到「拿东西」核对 → 点底部按钮**开始出行**。

## 3. 五个页面详解

### 3.1 「家」页（物品页 · 家的门面）

这里呈现的就是「你家」的样子：

- **资产卡**：抬头显示当前家的名字；左边是物品总数，右边是「已装入背包」（出行中变成「携带中」）。
- **家切换条**：一排胶囊就是你的全部家，黑色的是当前所在的家，点一下即可切换视角；末尾 **＋** 新建家。
- **当前背包卡**：你正在使用的背包、里面装了什么（图标速览），点「查看背包」看明细，点「换背包」切换。
- **全部家**：每个家一张卡，显示「物品 n · 背包 m」。**点开某个家**，才能看到这个家放了哪些背包、哪些物品（按分类分组的货架）。
- **背包详情**：从家详情或当前背包卡点进去——包里每件物品都写明**归属哪个家、从哪个家拿出来、什么分类、收录了多少天**。

操作提示：

- 物品行右侧 **＋** = 装包；再点变 ✕ = 移出背包。
- 点物品行本体 = 编辑（改名、换图标、换分类、归档）。
- 新添加的物品归属于「当时所在的/current 家」；从某个家的详情页里添加，则归属于那个家。

### 3.2 拿东西（出发的操作台）

- 上半部分是**已装入清单**：核对本次要带的东西，点行可移除。
- 下半部分是**货架剩余**：漏装的从这里点 **＋** 补装。
- 核对完点底部按钮**开始出行**。出行开始后清单自动锁定，防止误改。

### 3.3 检查（清点的对账台）

- **回家清点**：到家自动进入。逐行点勾确认「已带回」；找不到的先不勾。
- 点底部**完成清点**：没勾的物品进入「待确认」，保留 3 天——期间想起来了可在「我的 → 历史记录」补登；3 天后自动标记为**遗失**并给该物品记 1 次遗失。
- **到达其他地点**：到达公司等地点时，会请你「检阅」——勾选哪些物品放入此地（比如充电线常驻公司），没勾的继续随身携带。

### 3.4 地图（进阶模式）

已保存地点的分布、50 米围栏示意，以及每个家的「物品 n · 背包 m」速览。点地图上的大头针可切换当前家。

### 3.5 我的（资产与偏好的沉淀地）

- 「关于 Gowith」：一句话了解这款软件是什么。
- 历史记录：每次出行的完整清单与清点结果；待确认物品在这里补登。
- 偏好：出门/回家提醒、触感反馈；引导动画可重看。
- 谨慎操作：清空全部数据（不可恢复）。

## 4. 围栏与提醒（怎么知道你到家了）

- 每个地点有约 **50 米**的隐形围栏。出发后离开围栏，行程开始记录；进入任意已保存地点的围栏，App 会提醒你并自动进入清点/检阅。
- 没触发也没关系：**拿东西页 → 「手动确认到家或地点…」**可手动触发。
- 提醒需要定位权限：请选择「使用 App 期间 + 后台」；如果误关了，「我的」页会出现一键前往设置的恢复条。
- 基础模式只有三个页签；右上角切到「进阶」会解锁地图页与深色外观。

## 5. 待确认与遗失（东西真丢了怎么办）

1. 清点时没勾的物品 → **待确认**（检查页与「我的」角标会提示数量）。
2. 3 天内想起来了 → 「我的 → 历史记录」打开那次会议，补登为「已带回」。
3. 3 天后自动转为**遗失**，该物品的遗失次数 +1——经常丢的东西一眼可见。

## 6. 数据与隐私

- 所有数据（物品、背包、地点、历史）仅保存在手机本地的应用目录，不上传任何服务器。
- 物品照片会自动压缩后存储；删除物品/背包时照片一并删除。
- 目前没有云同步；换机时数据不会自动迁移。

## 7. 常见问题

**Q：为什么装包按钮是灰的？**
出发后清单锁定；或你不在当前地点 50 米围栏内（防止替别人改清单）。到家或结束行程后恢复。

**Q：为什么不能删除地点？**
地点里还有物品或背包时不允许删除；至少也要保留一个地点。先把物品移走。

**Q：背包删了，里面的东西呢？**
物品还在物品库里，只是不再装在任何背包里。删除背包不会删物品。

**Q：误点了「开始出行」？**
在拿东西页点「手动确认到家或地点…」选择出发地，即可进入清点并快速完成，不会产生异常记录。

**Q：图标找不到某个物品？**
「家」页顶部没有搜索——直接看「全部家」点对应家进入货架。

## 8. 手势速查

| 想做什么 | 怎么做 |
|---|---|
| 添加物品 / 背包 / 家 | 右下角 **＋** |
| 装包 / 移出背包 | 物品行右侧 **＋ / ✕** |
| 编辑物品 | 点物品行 |
| 切换当前家 | 「家」页家切换条 / 地图页大头针 |
| 看一个家里有什么 | 「家」页点开该家的卡片 |
| 看背包明细与归属 | 点当前背包卡「查看背包」 |
| 删除分类 | 物品页分类胶囊长按 → 编辑 |
| 手动触发到家 | 拿东西页 → 手动确认 |
