## 1. 数据层结论：不动模型

「家」的数据骨架已经存在，本轮**纯视图层重构**：

- `GowithPlace` = 家/地点（首启即建「我的家」）；
- `GowithItem.placeID` = 物品当前在哪个家（`nil` = 随身）；
- `GowithBackpack.placeID` = 背包在哪个家，`itemIDs` = 装了什么；
- `store.selectedPlaceID` / `selectedBackpackID` = 当前所在的家 / 正在使用的背包。

背包详情里「归属哪个家、从哪个家拿出来」的口径：

- 物品行归属 = `item.placeID`（在家名 / 随身）；
- 背包「从 X 拿出」= `backpack.placeID`（出行中为 nil，显示「随身」）。

## 2. 物品库 → 「家」页信息架构

一页一主任务的身份从「货架 + 数据台」升级为「**家的门面**」：先看见家与背包，再看见物品。

### 2.1 页面结构（自上而下）

```
┌─ 资产卡（深色 · home 纹样）────────────────┐
│ 「玉林的家」 · HOME            共 X 个家   │
│   N 件         │   M 件(橙)               │
│ 物品总数       │   已装入背包/携带中        │
│         点 + 添加物品 · 装包               │
└──────────────────────────────────────────┘
[ 家切换条 ●家A ○家B ○家C + ]   ← 一眼看到 & 一点切换当前家
[ 当前背包卡：登山包 · 正在使用 · 已装 N 件     ← 背包与内容透视图
  内容预览 chips · 查看背包 › · 换背包 ]
[ 全部家 · X 个 ]
[ 家卡：🏠 家A  物品 n · 背包 m   当前 › ]    ← 只有计数，不直接铺物品
[ 家卡：🏠 家B  物品 n · 背包 m       › ]
[ + 添加新物品… ]
（出行中锁定条 / 围栏提示条：位置不变）
```

- **(a) 选家**：家切换条胶囊直接切换 `selectedPlaceID`，当前家在资产卡抬头与「当前」徽标双重可见。
- **(b) 当前背包**：当前背包卡 = 背包预览 + 名称 + 已装件数 + 内容物 chips（最多 6 枚 + 溢出数）+「查看背包」「换背包」两个入口。
- **(c) 渐进展开**：家卡只显示计数；点开进入「家详情」sheet 才看到这个家的背包清单 + 物品货架（按分类分组，复用现有 ShelfRow）。原主页的平铺货架与分类 chips 移入家详情。
- **(d) 背包详情**：背包头（预览 + 名称 + 「从『家名』拿出」+ 件数）+ 物品行（缩略图 + 名称 + 属性行：`分类 · 归属「家名」· 持有 N 天`）。点行进入物品编辑。

### 2.2 家详情 sheet（HomeDetailSheet）

- 头卡：家名 + 物品/背包计数 +（当前家徽标）。
- 背包区：该家的背包行（预览 + 名称 + 已装 N 件），点击 → 背包详情；「新建背包」虚线入口（归属预置为该家）。
- 物品区：按分类分组的货架行；装包按钮仅在该家为当前家、且位于围栏内、且无进行中出行时可操作，否则只读（沿用 `isManageable` 语义，按家判定）。
- 底部「添加新物品」入口：新建物品归属预置为该家。

### 2.3 编辑器归属预置

`ItemEditorView` / `BackpackEditorView` 增加 `initialPlaceID` 参数：从家详情进入时新建的物品/背包归属该家；缺省仍为当前家。旧数据兼容：参数缺省即原行为。

### 2.4 其余页面联动

- 拿东西 / 检查 / 出行中逻辑完全不动（状态机、围栏、锁定语义不变）。
- 进阶地图页地点列表不动（低频总览台身份不变）。

## 3. 图形元素相似化

新增 AssetCard 纹样（Canvas 线稿，白 10–14% 透明度，与现有 flow/rings/crossCircle 同一语言）：

| 纹样 | 内容 | 用在 |
|---|---|---|
| `home` | 屋脊折线 + 圆角方形房屋轮廓（右上角） | 物品库（家）资产卡 |
| `backpack` | 背包圆角轮廓 + 顶提手（右上角） | 拿东西资产卡（替换 rings） |
| `crossCircle` | 保持 | 检查（已契合） |

家列表行使用统一房屋图形：圆角方形容器 + `house.fill`，当前家反色。装饰全部矢量代码绘制，不引入位图素材（遵守「不代做美术资产」的既往约定）。

## 4. 品牌资产

### 4.1 App 图标（极简）

- 画布 1024×1024：近黑渐变底（#1D1D20 → #0B0B0C，与深色资产卡渐变同源）；
- 主体：白色 heavy rounded「G」居中偏上，基线右侧橙色（#FF5A26）实心句点——即图标化的「Gowith**.**」句点记忆点；
- 单尺寸 1024 universal appiconset，`ASSETCATALOG_COMPILER_APPICON_NAME = AppIcon`。

### 4.2 启动屏

`UILaunchScreen.UIColorName` 指向 Assets 内纯黑颜色集（基础/进阶同色），静态屏与 Hero 帧无缝衔接。

### 4.3 Hero 品牌帧（沿用信息与引导方案 3.1 规格）

- 位置：冷启动首帧叠加层（教学/设置/主界面之上）；
- 时序：黑底常驻 → 字标浮现 0.25s → 句点 spring 落下 0.45s → 口号淡入 → 0.9s 内整体淡出移除；
- 口号（短版）：「出门带的，一件不少。」；
- 点按任意处立即跳过；热启动不显示；Reduce Motion 降级为简单淡入淡出。
