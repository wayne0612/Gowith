# Gowith「爽感」打磨方案

- 版本：1.0
- 日期：2026-09-25
- 目标：以商业软件的标准，把「用起来爽」变成可拆解、可实现、可验收的工程任务
- 依据：Apple HIG（反馈/触觉/动效）、神经与 UX 研究中的响应时间阈值（Doherty 阈值 400ms）、峰终定律（Kahneman）、游戏设计的 "juice" 理论，以及对 Gowith v1.1 全部界面的逐屏走查

---

## 0. 什么是「爽」：六条法则

「爽」不是装饰，是六种可测量的感受。每一条都有业界依据，也都能落到 Gowith 的具体界面上。

| 法则 | 一句话定义 | 底层依据 |
|---|---|---|
| **快** | 0.1 秒内必有响应，永远不等 | Doherty 阈值：<400ms 保持心流；Nielsen 0.1/1/10s 分层 |
| **顺** | 核心路径短到"没有感觉" | Fitts 定律；步骤数 × 每步摩擦 |
| **弹** | 每个动作都有看得见摸得着的物理后果 | 游戏设计 "juice"；micro-interactions 共识 |
| **懂** | 比用户先半步，被理解感 | 预判式 UI；上下文感知 |
| **稳** | 大胆点按也不会坏，可撤销、不丢数据 | 信任 = 敢用 = 用得爽 |
| **峰** | 精心设计那个值得记住的瞬间 | 峰终定律：人记住峰值和结尾，不是全程 |

业界共识（micro-interactions 研究）的四条补充约束：**每个动作立即有反馈；动效必须表达状态而非装饰；触觉是隐藏的愉悦层；时序 200–300ms 弹性缓动**。

## 1. Gowith 已经做对的（资产清单，迭代中不许丢）

这些是走查中验证过的爽感锚点，后续改动必须保持其水准：

1. **飞球装包动画**——"点 + → 球飞入角标 → 角标弹跳"是全 App 因果可见的标杆，弹感锚点
2. **黑白 + 单橙视觉**——净感的底子，任何新动效不得引入第二强调色
3. **触感语义体系**——selection / stateChange / success 各司其职，且有总开关
4. **围栏自动化**——回家自动切清点页，"被照顾感"的直接来源（懂）
5. **清点小贴士 / 待确认入口卡**——比用户先半步（懂）
6. **纯本地 + 原子写 + 孤儿归位**——稳的底子
7. **三帧教学动画**——合格的开场峰
8. **出行中锁定态**——把"防误操作"做成了仪式感

## 2. 差距与打磨清单

### P0 · 立即做（纯前端、低风险、爽感收益最大）

#### 2.1 完成清点的「峰值时刻」 【峰｜全产品最大的情绪浪费】

- **现状**：全产品情绪最高点应该是"全部带回"的那一刻，但现在它只是 `save() + 一次触感 + 跳回物品库`，无声无息地结束了。峰终定律告诉我们：用户对一次出行的记忆 = 峰值 + 结尾，而结尾现在被浪费了。
- **改法**：当会话以 **全部带回、零待确认** 完成时，插入约 1.5 秒的仪式画面（全屏遮罩或卡片放大转场）：大号 ✓ 描边生长动画 → "2/2 全部带回" → "连续零遗失 N 天"（数据已有：`zeroLostDays`）→ success 触感。有未确认项时**不**触发（对比之下强化"完整带回"的价值）。
- **边界**：≤1.5 秒、点击任意处跳过、Reduce Motion 降级为淡入淡出、VoiceOver 有完整语义。
- **验收**：全带回完成 → 出现仪式画面且自动消失；有待确认项 → 不出现；Reduce Motion 开启 → 无位移动画。

#### 2.2 资产卡大数字滚动 【弹｜一行级改动，收益最大】

- **现状**：50pt ExtraBold 主数字在数据变化时是瞬时跳变（2→0、0→2），生硬。
- **改法**：iOS 17 原生 `contentTransition(.numericText(value:))` + spring 动画，数字滚动/推移过渡。
- **验收**：装包/卸包/清点打勾时，四个页面的资产卡数字均有 ≤300ms 的滚动过渡；Reduce Motion 下直接切换。

#### 2.3 全局按压反馈 【快｜"按下去没反应"是爽感头号杀手】

- **现状**：走查实测——所有自定义按钮按下无任何视觉响应（无 pressed 态），用户感知延迟就是整段动画时长。
- **改法**：统一定义 `GowithPressableButtonStyle`（scale 0.96 + 透明度 0.8，80ms spring），主按钮/次按钮/行按钮/Tab 图标全部套用。
- **验收**：任意可点元素按下瞬间有缩放反馈；手指不抬起松开则回弹。

#### 2.4 卸包的对称反馈 【弹】

- **现状**：装包有飞球（满分级），卸包（点 ✕ 或清单行取消）只有行状态翻转——因果链不对称，"拿掉"这个动作没有分量。
- **改法**：卸包时反向反馈——小球从「拿东西」角标飞回行位置并淡出（复用 PackFlight 机制反向），或行内容 6pt 轻抖 + 角标缩回。择一实现，成本远低于飞球。
- **验收**：卸包有可感知的方向性反馈；Reduce Motion 降级为角标缩放。

#### 2.5 列表级联入场 【弹】

- **现状**：Tab 切换是整页 opacity + scale 过渡，内容一次性出现，缺少"活"的感觉。
- **改法**：货架行/清单行做 30ms 逐行级联（淡入 + 上移 8pt），仅在本页首次出现时触发，滚动不重放。
- **验收**：切换 Tab 有级联但无累赘感；Reduce Motion 全降级。

#### 2.6 模式切换的色彩过渡 【弹｜技术债清偿】

- **现状**：基础/进阶切换是瞬时翻转（响应明确但生硬）。记忆档已记录：三条错误路径（.id 重建/遮罩延迟动画/环境覆盖）都触过雷，正确解法是**色板显式驱动**。
- **改法**：`GowithColor` 从 UIColor trait 动态色改为按 `AppMode` 显式取值（静态字典），切换时 `withAnimation` 对颜色插值，全局平滑过渡；同步删除 `preferredColorScheme` 依赖。涉及全部令牌，是一次系统性但边界清晰的重构。
- **验收**：切换模式所有界面颜色平滑过渡（≤400ms）；三个历史毒坑场景（胶囊/底栏/内容）无冻结；深浅色外观跟随系统仍正确。

### P1 · 功能级（中成本，差异化利器）

#### 2.7 一键复装 【懂｜零网络，纯本地数据】

- **现状**：「可能还想带」退化为货架剩余，没有真正的"预判"。
- **改法**：拿东西页新增「上次出门」卡：列出最近一次完成会话携带的物品，一键全部装入（逐个触发飞球，形成连击爽感）。数据源现成（历史会话 items）。差旅/通勤党的最高频动作就是"和上次一样"。
- **验收**：完成过 ≥1 次出行后，拿东西页出现该卡；一键复装后清单与上次一致；无历史时隐藏。

#### 2.8 Live Activity 灵动岛 【懂+峰｜同类没有的差异化】

- **现状**：出行期间 App 外毫无存在感，用户不知道 App 在替他记着。
- **改法**：出行开始 → 启动本地 Live Activity：灵动岛/锁屏显示「出行中 · 2 件 · 已出门 N 分钟」（计时实时刷新）；围栏触发到家 → 更新为「到家了 · 开始清点」，点击直达检查页；会话完成 → 结束。ActivityKit 本地活动**不需要付费账号与推送**，侧载可用。
- **验收**：出行开始 1s 内灵动岛出现；模拟器围栏触发时内容更新；完成清点后消失。

#### 2.9 App 长按快捷 + App Intents 【顺】

- **现状**：所有入口都要先进 App。
- **改法**：主屏长按图标：开始出行 / 完成清点 / 查看携带；注册 App Intents 供快捷指令与 Siri（"嘿 Siri，开始出行"）。Spotlight 收录物品。
- **验收**：长按出现三项且动作正确；快捷指令 App 中可搜到并串联自动化。

#### 2.10 数据导出 / 导入 【稳｜商业化前置项】

- **现状**：换机 = 全部记录蒸发，是用户"敢不敢认真用"的天花板。
- **改法**：我的 → 导出（JSON + 图片打包为单个文件，分享面板存档）；导入（解析、校验、合并策略：覆盖或合并）。
- **验收**：导出 → 删除 App → 重装 → 导入，全部数据与图片完整还原。

## 3. 标杆样本（各学一件事）

- **Things 3**：动效与触感的"手感"是产品溢价本身——学它"每个动作都有重量"的克制打磨，不学它的复杂度
- **Flighty**：Live Activity 的天花板——锁屏上 App 比打开时更有用，正是 Gowith 出行态该有的样子
- **Duolingo**：streak（连续纪录）的情绪设计——Gowith 的「连续零遗失」不该埋在历史页，应该被庆祝
- **Apple 健身圆环**：把抽象数据变成闭合的物理隐喻——✓ 描边生长动画的参照
- **网易云音乐年度报告**：数据资产化与情感峰值的样本——"第 N 次零遗失"是 Gowith 的同款资产

---

## 4. 不做什么（克制的边界）

1. **不加装饰性动效**——每个动画必须表达状态变化或引导注意，否则砍掉
2. **不做签到/积分/勋章墙式游戏化**——与黑白克制的品牌人设冲突；streak 只在峰值时刻出现
3. **不为爽感破坏纯本地承诺**——一切联网能力（天气等）必须用户显式开启
4. **不做打断式庆祝**——峰值画面 ≤1.5s、可跳过、尊重 Reduce Motion
5. **不加第二个强调色**——橙色是唯一的情绪出口

---

## 5. 验收方法

1. **动效类**：`xcrun simctl io --record` 逐帧回看曲线与时序；模拟器 CUA 点测全流程
2. **降级类**：开启 Reduce Motion / VoiceOver 各走一遍核心闭环
3. **性能类**：Instruments 冷启动 ≤800ms 首帧可用；滚动无掉帧（重点盯黑色资产卡投影）
4. **场景类**：以「出差党一日」为剧本完整走查（出发→到达→回家→峰值时刻→复装）
5. 每完成一项在本文档勾选，并计入 v1.1.x 记录批次
