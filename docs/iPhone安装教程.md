# Gowith 1.0 · iPhone 安装教程（免付费开发者账号）

> 目标：把 Gowith 1.0 装到你的 iPhone 上，全程不需要购买 Apple 开发者账号（$99/年）。
>
> 安装包：`dist/Gowith-1.0.0-unsigned.ipa`（Release 构建、arm64、版本 1.0、最低要求 iOS 17.0）

---

## 一、先搞清楚：为什么不能"拿到安装包直接点开就装"

安卓的 `.apk` 可以直接传到手机安装，但 **iOS 的任何安装包（.ipa）都必须携带有效签名**，手机才会执行它。签名只能由 Apple 签发，来源只有三种：

| 方式 | 费用 | 说明 |
| --- | --- | --- |
| App Store / TestFlight | ¥688/年（付费开发者账号） | 你目前没有，走不通 |
| 企业签名 | 极贵且不稳定 | 不考虑 |
| **免费 Apple ID 个人签名** | **免费** | **本教程的路线**：安装时用你自己的免费 Apple ID 现场签名 |

所以结论是：**安装包我做不了"已签名"的**（没有付费账号，签名必须含你本人 Apple ID 的证书），但可以把"签名"这一步压缩到安装时由工具自动完成——你只需要一个免费 Apple ID、一根数据线、一台电脑（Mac 或 Windows 都行），大约 10 分钟装好。

### 免费签名的限制（先知道，免得之后意外）

- **有效期 7 天**：7 天后 App 打不开，需连电脑重新签一次（几十秒的事，数据保留）
- 同一台手机**最多同时装 3 个**这样签名的 App
- 不支持推送等特殊能力（Gowith 只用本地通知，**不受影响**）

## 二、准备工作

1. iPhone 一台，系统 **iOS 17.0 或更高**（Gowith 最低要求 iOS 17；在手机的 设置 → 通用 → 关于本机 可查看）
2. 免费 Apple ID（就是你 iPhone 上登录的那个邮箱账号即可）
3. 数据线（Mac/Windows 电脑和手机之间）
4. 下载 **Sideloadly**（签名安装工具，免费）：<https://sideloadly.io>，选对应系统版本安装

---

## 三、路线 A：Sideloadly 安装（推荐，最简单）

### 在电脑上

1. 数据线连接 iPhone 和电脑。**手机上如果弹出"要信任此电脑吗？"，点「信任」并输入锁屏密码。**
2. 打开 Sideloadly：
   - 第一行 **Apple ID**：输入你的 Apple ID 邮箱
   - **IPA**：把 `dist/Gowith-1.0.0-unsigned.ipa` 拖进窗口（或点选择文件）
   - 其他选项全部保持默认，**不要改** Bundle ID 相关选项
3. 点右下角 **Start**。
4. 弹出密码框时输入 Apple ID 密码。**如果你的 Apple ID 开了双重认证**（大概率开了），这里要输入的不是登录密码，而是「App 专用密码」：
   - 浏览器打开 <https://account.apple.com> → 登录 → 「登录与安全」→ **App 专用密码** → 生成一个（名字随意，如 `sideloadly`）→ 复制这串密码（形如 `abcd-efgh-ijkl-mnop`）→ 粘贴到 Sideloadly 的密码框
5. 等待进度走完（几分钟），手机上会多出 Gowith 图标。**此时先别点开**，先做下面手机端的信任设置。

### 在手机上（一次性设置）

6. **开启开发者模式**（iOS 16+ 必需）：
   - 点开 Gowith 图标，若提示"需要开发者模式"，点提示里的「打开」；或者直接去 **设置 → 隐私与安全性 → 开发者模式** → 打开 → 按提示**重启手机**
   - 如果看不到这个开关：重启一次手机再看；仍没有就说明 App 还没装成功，回到电脑端重装
7. **信任开发者证书**：
   - **设置 → 通用 → VPN 与设备管理** → 找到 **Apple Development: 你的AppleID邮箱** → 点「信任 **你的AppleID邮箱**」→ 确认
8. 回到主屏，点开 **Gowith** —— 第一次会请求定位权限（用于地理围栏核心功能），选「使用 App 期间」或「始终」都可以；相机/相册权限在你用到拍照/选图功能时再允许即可。

✅ 完成。App 已经在你的手机上，数据全部存在手机本地，不联网。

## 四、路线 B：AltStore 安装（推荐长期使用者，7 天自动续签）

Sideloadly 的缺点是 7 天后要手动重签。**AltStore** 装好后，只要电脑上的 AltServer 开着、手机和电脑在同一 Wi-Fi，就会**自动续签**，你完全不用管。

1. 电脑安装 **AltServer**：<https://altstore.io>（Mac / Windows）
2. 手机装「AltStore」App：Mac 上点菜单栏 AltServer 图标 → Install AltStore → 选你的 iPhone（需要同一 Wi-Fi + 数据线首次配对）
3. 手机打开 AltStore → 底部 **My Apps** → 右上角 **+** → 选择 `Gowith-1.0.0-unsigned.ipa`
4. 同样完成上文第 6、7 步（开发者模式 + 信任证书）

之后每 7 天自动续签，无需你操作。**如果想长期每天用 Gowith，建议用这条路线。**

---

## 五、路线 C：用 Xcode 直接从源码安装（你手头就有工程）

你的 Mac 上已装好 Xcode 26.6，工程就在本仓库 `Gowith/Gowith.xcodeproj`。这条路最"官方"，而且以后改了代码随时能装新版：

1. 双击打开 `Gowith/Gowith.xcodeproj`
2. Xcode 菜单 **Xcode → Settings… → Accounts** → 左下角 **+** → 登录你的 Apple ID
3. 左侧文件列表点最顶上蓝色的 **Gowith** 工程 → 中间选 **Gowith** 目标 → **Signing & Capabilities** 标签：
   - **Team** 下拉选择「你的名字 (Personal Team)」
   - 若报 Bundle ID 冲突，把 **Bundle Identifier** 从 `com.gowith.app` 改成一个独特的，如 `com.你的名字.gowith`
4. 数据线连接 iPhone，Xcode 顶部设备栏选择你的 iPhone（手机上点「信任」）
5. 按 **Cmd+R** 运行。若提示需要下载 iOS 平台组件，按提示下载一次（约 8GB，只需一次）
6. 手机上完成和路线 A 相同的「开发者模式 + 信任证书」两步

---

## 六、7 天到期后怎么办

- 现象：App 图标变暗 / 打开时提示"无法验证 App"
- 处理：手机连电脑——
  - Sideloadly 路线：重跑一次第三节的流程（1 分钟），**App 数据会保留**
  - AltStore 路线：连一下电脑（或确认同 Wi-Fi 下 AltServer 在运行）会自动续签
- 保持**同一 Apple ID、同一工具**重签，数据就不会丢

## 七、常见问题排查

| 现象 | 原因与处理 |
| --- | --- |
| Sideloadly 报密码错误 | 双重认证账号必须用「App 专用密码」，见第三节第 4 步 |
| 提示 maximum Bundle IDs / provisioning | 免费账号 7 天内最多注册 10 个 App ID、同时装 3 个侧载 App；删掉不用的或等几天 |
| 手机上没有"开发者模式"开关 | 先确认 App 已装上；重启手机；或先用 Xcode 连一次手机再找 |
| 点 App 提示"不受信任的开发者" | 没做第三节第 7 步的信任操作，去 设置 → 通用 → VPN 与设备管理 |
| 安装后打不开 / 图标发灰 | 签名过期（超过 7 天），重新签名即可 |
| Sideloadly 一直卡住 | 换一根数据线 / 换 USB 口；Windows 下暂时关闭杀毒软件 |
| 提示 iOS 版本过低 | Gowith 最低要求 iOS 17.0，手机需升级系统 |
| 想确认装的是不是 1.0 版 | 设置 → 通用 → iPhone 储存空间 → Gowith，可看到版本号 1.0 |
